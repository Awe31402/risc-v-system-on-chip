# 23.5 Summary

> 原書 p.784.e105（Chapter 23: FPGA Implementation）
> 註：書中正文將此節編為「23.4 SUMMARY」（章首目錄作 23.5）

## 這節在講什麼

第 23 章，也是本書正文最後一章的總結。三段話。

## 關鍵點

### 從 CPU 到電腦要補什麼

> "This chapter has shown how to implement Wally on AMD FPGAs ranging from a midrange Digilent Arty A7-100T board or a high-end AMD VCU108 FPGA evaluation board. The fpgatopArtyA7 SystemVerilog module instantiates the wallypipelinesoc, along with clock and reset circuitry, an AXI bridge to a DDR DRAM memory controller, an SD card controller for an on-board flash memory, and a UART-to-USB interface to communicate with a terminal on a host computer."
> — p.784.e105

中文解釋：**四樣東西把 CPU 變成電腦**——時脈與重設、記憶體控制器（加匯流排橋接）、非揮發性儲存、人機介面。前 22 章都在講 `wallypipelinedsoc` 裡面的東西，這一章講外面的。

### 模擬與真實硬體的唯一差別

> "The Wally ZSBL reads the OpenSBI bootloader, device tree, and Linux kernel from the SD card into DRAM and then jumps to the OpenSBI bootloader. The remainder of the OS boot is the same on an FPGA as in simulation."
> — p.784.e105

中文解釋：**只有 ZSBL 不一樣。** 模擬裡 testbench 直接把檔案塞進記憶體（22.2.5 的 18 條指令版 ZSBL 只是跳過去），FPGA 上要真的從 SD 卡搬。從 OpenSBI 開始，後面五億條指令完全相同。

這是一個很好的分層設計證明——**平台相關的部分被壓縮到最小的那一塊**。

### FPGA 的價值與代價

> "FPGAs are invaluable tools in verification and performance analysis. Using the higher performance of FPGAs, Wally is able to execute hundreds of billions of instructions faster to find bugs the standard regression test failed to uncover in simulation. FPGAs tradeoff execution speed for internal signal visibility, making debugging harder when a bug is detected. Finally, the FPGA implementation aided in identifying key critical path issues without the effort of going through an ASIC synthesis and place and route step."
> — p.784.e105

中文解釋：這段把 FPGA 的定位講得最清楚——**三個價值、一個代價**：

**價值：**
1. **跑得夠多才抓得到 bug**——「數千億條指令」，這是模擬做不到的（第 22 章：模擬一次五億條要 20 小時）
2. **找關鍵路徑不必走完整的 ASIC 流程**——23.4.3 節的 15 → 20 MHz 就是這樣做出來的
3. 能接真實的外部硬體（SD 卡、DDR3、終端）

**代價：**
- **用執行速度換走了內部訊號的可見度**——在模擬裡每條線都看得到，在 FPGA 上只有 ILA 探測的那幾條。23.4.1 節反覆重跑開機才找到根因，就是這個代價的實際樣子。

## 名詞表

| 名詞 | 意思 |
| --- | --- |
| `fpgatopArtyA7` | 包住 `wallypipelinedsoc` 與所有周邊 IP 的頂層模組 |

## 所以呢

本書正文到此結束。整條路走完了——從第 1 章的 ISA 概念，到 RTL 實作、各種擴充、驗證、效能分析、跑 Linux，最後燒進一顆 $299 的 FPGA 變成一台真的能打字的電腦。

FPGA 這一章在整本書裡的位置很特別：**它是唯一一個「抽象層全部拿掉」的地方**。模擬裡所有東西都是理想的（記憶體立刻回應、訊號沒有延遲、每條線都看得到），而 FPGA 上會遇到上拉電阻不匹配、JTAG 時脈太快、關鍵路徑跑不到目標頻率、以及只有真實時序巧合才會現形的 bug。
