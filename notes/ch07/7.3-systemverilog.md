# 7.3 SystemVerilog

> 原書 p.328–329（Chapter 7: Pipelined Core）

## 這節在講什麼

**很短，只有兩段。交代這一章的設計在程式碼裡的哪裡、用哪個組態。**

三件事：
1. **哪個組態對應這一章**（`rv64i`、`rv32i`、`rv32e`）
2. **`rv32e` 的兩個額外差異**
3. **一個重要提醒：原始碼是完整的，這一章只是它的一個子集**

## 關鍵點

### 對應的組態

> "The Wally configurable pipelined processor is implemented in SystemVerilog. It uses
>  **`$WALLY/config/rv64i/config.vh` to specify the set of supported features described in this
>  chapter for a 64-bit processor. The rv32i configuration is similar.**"
> — p.328

中文解釋：**這一章的內容 = `rv64i` 或 `rv32i` 組態。**
（呼應 4.4 節：組態檔在 `$WALLY/config/<name>/config.vh`。）

### rv32e 的兩個差異

> "**Wally's rv32e configuration is also similar, but minimizes size by shrinking the register file
>  from 32 to 16 entries and replacing the IROM and DTIM with an AHB interface to off-chip memory
>  described in Section 9.5.**"
> — p.329

中文解釋：**`rv32e` 不只是「暫存器少一半」，還有第二個差異：**

| 差異 | 內容 |
| --- | --- |
| **暫存器檔案** | **32 → 16 項**（呼應 2.5 節：省約 1/4 核心面積） |
| **記憶體** | **用 AHB 介面接晶片外記憶體，取代 IROM 和 DTIM** |

**第二點解釋了 6.5.3 節 Table 6.8 的一個數字：
rv32e 的 LSU 只有 470 μm²，而 rv32i 是 15,328 μm²——
因為 rv32e 沒有 DTIM，只有一個匯流排介面。**

（AHB 介面在第 9.5 節。）

原始碼位置：**`$WALLY/src`。**

### 最重要的提醒：程式碼是完整的

> "**The full source code contains conditional generate statements to produce only the configured
>  hardware. However, it has modules and ports sufficient to support all configurations.
>  It is worth reading and relating to the diagrams in this chapter and the coding guidelines from
>  Section 4.3 to get an understanding of the processor design.**"
> — p.329

中文解釋：**這段是讀 Wally 程式碼時最該記住的心理準備：**

**你打開 `ieu.sv` 會看到一堆這一章沒講到的訊號和模組**——
那些是給其他組態用的（FPU、MDU、privileged 等）。
**條件產生（conditional generate）會在編譯時把它們拿掉，
但模組和埠是為了支援所有組態而寫的。**
（呼應 4.2.5.3 節的 conditional generate、4.3 節 Guideline 4.40「介面不隨組態改變」。）

**閱讀建議（p.329）：
「把程式碼和本章的圖、以及 4.3 節的編碼規範對照著讀。」**

**具體做法：**
1. 先看本章的方塊圖（Fig. 7.2 單週期、Fig. 7.13 pipeline）
2. 對照 4.3.1 節的命名規範（**UpperCamelCase + F/D/E/M/W 後綴 + 單元前綴**）
3. 對照 4.3.4 節的模組規範（**資料通路用結構化風格、控制用行為風格**）

## 名詞表

| 名詞 | 意思 |
| --- | --- |
| `rv64i` / `rv32i` | 本章對應的組態 |
| `rv32e` | 最小組態：**16 個暫存器 + AHB 外部記憶體介面**（無 IROM/DTIM） |
| AHB | 一種晶片內匯流排協定（第 9.5 節） |
| Conditional generate | 條件產生。只產生所選組態需要的硬體（見 4.2.5.3 節） |

## 所以呢

**這一章的程式碼在 `$WALLY/src`，組態是 `rv64i` / `rv32i` / `rv32e`。**

兩個閱讀時要記住的事：
1. **`rv32e` 除了暫存器減半，還把 IROM/DTIM 換成 AHB 外部介面**——
   這解釋了它為什麼那麼小。
2. **程式碼裡有大量本章用不到的訊號和模組**——
   那是為了支援所有組態，靠 conditional generate 在編譯時篩掉。
   **對照本章的方塊圖和第 4.3 節的命名規範來讀，才不會迷路。**

下一節（7.4）是測試計畫。
