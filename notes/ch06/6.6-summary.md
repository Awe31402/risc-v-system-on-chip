# 6.6 Summary

> 原書 p.297（Chapter 6: Logic Synthesis）

## 這節在講什麼

第 6 章總結，兩段。

第一段回顧三種製程技術的定位，**其中「TSMC 28nm 是 FinFET 出現前最後一個主流平面製程」
這個歷史定位值得記住。**

第二段是 Wally 的最終數字，**而且點明了兩個組態各自被什麼限制住——
這比單純的數字更有意義。**

## 關鍵點

### 三種製程的定位

> "Logic synthesis maps synthesizable HDL code onto a cell library, minimizing area subject to a
>  clock frequency constraint. This chapter examines the capabilities of three CMOS technologies.
>  **The older Skywater Technology 130- and 90-nm processes (SKY130 and SKY90) are low-cost
>  technologies suited for microcontrollers and other chips of modest complexity.**"
> — p.297

中文解釋：**再次確認合成的目標函數**（呼應 6.1 節）：
**「在時脈頻率約束下，把面積最小化」**——
**時脈是約束，面積是目標。**

**SKY130/SKY90 的定位：低成本，適合微控制器和複雜度中等的晶片。**

### TSMC28 的歷史定位（很值得記）

> "**The newer TSMC 28 nm process (TSMC28) is the last of the mainstream planar processes before
>  the advent of FinFETs, costly multipatterning, and draconian nondisclosure agreements (NDAs)
>  that appeared starting with the 16-nm process.** TSMC 28 is available for academic research and
>  modern enough to be relevant for some commercial products. **It also has an industry-strength
>  set of libraries, including a memory compiler that can produce the SRAM memories needed for
>  Wally's caches and branch predictor.**"
> — p.297

中文解釋：**這段解釋了「為什麼是 28nm」——三個門檻從 16nm 開始出現：**

| 門檻 | 意義 |
| --- | --- |
| **FinFET** | 立體電晶體，設計複雜度上升（呼應 6.2 節） |
| **昂貴的 multipatterning（多重曝光）** | 光刻波長不夠，一層要曝光多次，成本暴增 |
| **嚴苛的 NDA** | **學術界拿不到**（呼應 6.2 節：28nm NDA 要三個月，1.2 萬美元） |

**所以 28nm 是「學術界能碰到的最先進、又還算跟得上商業產品」的甜蜜點。**

**而且它有「業界強度的元件庫，含能產生 SRAM 的記憶體編譯器」**——
這對 Wally 的 cache 和分支預測器是必要的（呼應 6.2.3、6.5.3 節）。

### 兩個製程世代的差距

> "**The 28-nm process is 3-4x faster and offers about 8x better density and dynamic energy than
>  the 90-nm process.**"
> — p.297

中文解釋：**SKY90 → TSMC28 的三個數字：**

| 指標 | 改進 |
| --- | --- |
| **速度** | **快 3–4 倍** |
| **密度** | **好約 8 倍** |
| **動態能量** | **好約 8 倍** |

**（對照 Table 6.3 的 32-bit 加法器：延遲 449 → 100 ps 是 4.5 倍、
面積 1,441 → 209 μm² 是 6.9 倍、動態能量 658 → 82 fJ 是 8 倍。吻合。）**

### Wally 的最終數字，以及各自的瓶頸

> "This chapter has illustrated how to use a Make-based script to synthesize Wally using the
>  industry-standard Synopsys Design Compiler and how to interpret performance, power, and area
>  (PPA) reports."
> — p.297

> "In the 28-nm process, **rv32e consumes about 6,500 logic cells (0.007 mm²) and operates up to
>  2.8 GHz, limited by the Execute stage branch logic.** rv64gc consumes about **200,000 logic
>  cells and 42 RAM macros (0.5 mm²) and operates at 800 MHz, limited by the time for the TLB and
>  PMP to detect an illegal physical address, generate a fault, and update the program counter to
>  fetch the next instruction from the trap handler.**"
> — p.297

中文解釋：**兩個組態的完整檔案，這是全章的結論：**

| | **rv32e** | **rv64gc** |
| --- | --- | --- |
| 邏輯元件數 | **6,500** | **200,000**（+ 42 個 RAM macro） |
| 面積 | **0.007 mm²** | **0.5 mm²**（**71 倍**） |
| 頻率 | **2.8 GHz** | **800 MHz**（**慢 3.5 倍**） |
| **瓶頸** | **Execute 級的分支邏輯** | **TLB 和 PMP 偵測非法實體位址 → 產生 fault → 更新 PC 去 trap handler** |

**「瓶頸是什麼」比「頻率是多少」更有價值**，因為它告訴你該往哪裡改進。

**rv32e 的瓶頸（Execute 級分支邏輯）**呼應 6.4.4 節逐格追蹤的那條關鍵路徑：
轉發 → 32-bit 比較器（10 層邏輯）→ PCSrc → Stall/Flush。

**rv64gc 的瓶頸是完整的 trap 產生路徑**——
**位址轉換 + 權限檢查 + 例外產生 + PC 更新，全部要在一個週期內完成。**
（這條路徑會在第 8、11 章詳細展開。）

**（注意：6.5.3 節邊欄說過，rv64gc 的 PMP 路徑結果「不如預期，
可能是合成實驗有問題」——所以這個數字要保留一點懷疑。）**

## 名詞表

| 名詞 | 意思 |
| --- | --- |
| Multipatterning | 多重曝光。光刻波長不足時一層曝光多次，成本高；16nm 起成為門檻 |
| Memory compiler | 記憶體編譯器。產生 SRAM 巨集的工具 |
| RAM macro | 記憶體巨集。rv64gc 用了 42 個 |

## 所以呢

**第 6 章的核心：合成是「在時脈約束下最小化面積」，
而評估結果要看 PPA 三個指標。**

四件帶得走的事：

1. **TSMC 28nm 是「FinFET、multipatterning 和嚴苛 NDA」出現前
   最後一個主流平面製程**——所以它是學術界的甜蜜點。

2. **90nm → 28nm：快 3–4 倍、密度和動態能量各好約 8 倍。**

3. **rv32e：6,500 個邏輯元件、0.007 mm²、2.8 GHz，
   瓶頸在 Execute 級的分支邏輯。**

4. **rv64gc：200,000 個邏輯元件 + 42 個 RAM、0.5 mm²、800 MHz，
   瓶頸在 TLB/PMP 的非法位址偵測到 trap 處理的完整路徑。**

**兩個組態差 71 倍面積、3.5 倍頻率——這就是「功能不免費」的最終量化。**
