# 23.1 FPGA Principles

> 原書 p.784.e78–784.e80（Chapter 23: FPGA Implementation）
> 涵蓋 23.1.1 FPGAs

## 這節在講什麼

最後一章把 Wally 做進真實硬體。23.1 是 FPGA 的背景：它是什麼、為什麼存在、和 ASIC 怎麼取捨。

核心觀念只有一個——**FPGA 用「每顆晶片比較貴、比較慢」換「不用付幾百萬美元的光罩費、改一次設計只要幾分鐘」**。

## 關鍵點

### FPGA 是什麼

> "A field programmable gate array (FPGA) contains a configurable array of logic elements (LEs), memories, input/output (I/O) pins, and routing cells that can be programmed to perform arbitrary digital functions. To program an FPGA, design tools translate RTL (e.g., SystemVerilog code) into a bitstream, which configures the FPGA as particular logic functions, memory, and interfaces."
> — p.784.e78

中文解釋：關鍵字是 **bitstream**——一份設定檔，載進去就決定了這顆晶片現在是什麼電路。

### NRE vs per-unit：為什麼 FPGA 存在

> "Semiconductor economics considers both nonrecurring engineering costs (NREs) and per-unit cost. The NRE to create a mask set for an application-specific integrated circuit (ASIC) runs in the millions of dollars, and fabrication takes 3−12 weeks. Each chip typically costs less than $100 (perhaps less than $1 for simple chips). In contrast, an FPGA evaluation board typically costs between $100 and $10,000, and a new bitstream can be created and downloaded in minutes to days depending on the size of the design."
> — p.784.e78

中文解釋：**這是整節最重要的經濟學**：

| | ASIC | FPGA |
| --- | --- | --- |
| NRE（一次性成本） | 數百萬美元的光罩 | 幾乎為零 |
| 製造/修改時間 | 3–12 週 | 幾分鐘到幾天 |
| 每顆成本 | < $100（簡單的 < $1） | $100–$10,000 的開發板 |

**分界點在產量**。賣幾千台的產品，ASIC 的 NRE 攤下來遠超過 FPGA 的單價差；賣幾百萬台就反過來。

### FPGA 對開發的三個好處

> "FPGAs are suitable for rapid prototyping, as opposed to ASIC test chips, which are expensive and time-consuming to design and build. Running a system in hardware (on an FPGA) is faster than in simulation, and an FPGA can interact with external hardware in a way that is difficult to model in simulation. When a bug is found, the designer can generate and download a new bitstream to reprogram the FPGA."
> — p.784.e78

中文解釋：三個好處——**快速原型、比模擬快（第 22 章的數字：幾分鐘 vs 20 小時）、能接真的外部硬體**。第三點特別重要：SD 卡、DDR3 記憶體、真的 UART 終端，這些在模擬裡要嘛做不到、要嘛模型和真實行為有落差。

### 效能取捨

> "Compared to ASICs, FPGAs tend to run at an order of magnitude lower clock frequency and cost two orders of magnitude more per gate. However, with parallelism and special-purpose logic, FPGAs can far exceed the performance and performance/watt of a general-purpose microprocessor."
> — p.784.e78

中文解釋：**慢 10 倍、每個閘貴 100 倍**——這解釋了為什麼第 23.2 節的 Wally FPGA 只跑 20 MHz（而 ASIC 版本可以跑到幾百 MHz）。

但第二句是重點：**FPGA 打不過 ASIC，卻可能打贏通用 CPU**——因為它能為特定演算法做大量平行的專用電路。這就是 FPGA 在通訊、科學運算、醫療、軍事、航太的用武之地。

### emulation：驗證的工業級用法

> "FPGAs are also used in emulation, a logic verification technique where the design is mapped onto an FPGA so that large numbers of tests can be run on physical hardware at a much faster rate than is possible in software simulation. FPGAs may include an integrated logic analyzer (ILA) to improve observability and controllability during testing. Industrial SoC design teams use commercial FPGA-based emulation systems to replace hundreds of servers running verification tests for months or years."
> — p.784.e79

中文解釋：**這是 FPGA 在業界最重要的用途之一**。「取代數百台伺服器跑數月或數年的驗證測試」——這個數字說明了模擬的成本有多高（回想第 22 章：模擬一次 Linux 開機要 20 小時）。

**ILA（integrated logic analyzer，內建邏輯分析儀）**解決了 FPGA 的最大缺點：在模擬裡你能看到每一條線，在真實硬體上什麼都看不到。ILA 是燒進 FPGA 裡的一小塊電路，會把指定的訊號記錄下來讓你事後檢視——用一點面積換回觀測能力。

### FPGA 的內部結構

> "FPGAs evolved from programmable logic array (PLA) chips, which were developed in the early 1980s to perform arbitrary sum-of-product functions. The hardware costs of PLAs grow quadratically with complexity, so FPGAs were developed in the mid-1980s as a more flexible way to implement larger systems."
> — p.784.e79

中文解釋：PLA 的成本是**平方成長**，所以做不大。這是 FPGA 誕生的直接原因。

> "An FPGA has an array of programmable LEs connected by programmable interconnect. Each LE typically contains a lookup table (LUT) and a register. The LUT is a small memory that performs any combinational function of a small number of inputs (typically 4-6). An FPGA performs complex logic functions by connecting outputs of one LE to the inputs of another."
> — p.784.e79

中文解釋：**LUT 是 FPGA 的核心概念**——一個 4–6 輸入的小記憶體，裡面存著真值表。要實作任何 4 輸入的邏輯函數？把真值表寫進 LUT 就好，不用真的接邏輯閘。

Fig. 23.1 的結構：LE 陣列 + 周圍的 IOE（I/O element）+ 交叉點上的可設定開關。**bitstream 就是「所有 LUT 的內容」加「所有開關的設定」**。

（術語混亂：Altera/Intel 叫 logic elements (LEs)，Xilinx/AMD 叫 configurable logic blocks (CLBs)。）

> "Most modern FPGAs use static random access memory (SRAM) for configuration memory."
> — p.784.e79

中文解釋：**用 SRAM 存設定表示斷電就忘記**——每次開機都要重新載入 bitstream。這是為什麼 FPGA 板子上通常還有一顆 flash。

### 現代 FPGA 不只有 LUT

> "Large FPGAs now contain millions of LEs, along with other specialized blocks such as hundreds of megabits of SRAM, thousands of digital signal processing (DSP) units, high-speed serial I/O, multicore microprocessors, and clock generators. FPGAs also come with intellectual property (IP) libraries that include memory controllers, bus interfaces, and a variety of peripherals."
> — p.784.e79

中文解釋：**純 LUT 做乘法器和記憶體太浪費**，所以現代 FPGA 內建了硬式的 DSP 單元（乘加器）和 block RAM。下一節會看到 Wally 用到的 Artix-7 有 240 個 DSP slice 和 4,860 KiB 的 block RAM。

**IP 函式庫**也很關鍵——DDR3 記憶體控制器這種東西自己寫要好幾個月，AMD 直接提供。23.2 節的 Wally FPGA 就用了五個 AMD IP 模組。

> "Vendor-specific electronic design automation tools synthesize HDL code and map it onto a specific FPGA. In addition to design files, users provide constraint files that specify I/O pin assignments and target clock rate."
> — p.784.e79–e80

中文解釋：**constraint file（約束檔）是 FPGA 流程特有的**——RTL 只描述邏輯，但實體上「這條訊號接到板子上哪根腳位」「目標時脈多快」必須另外告訴工具。

## 名詞表

| 名詞 | 意思 |
| --- | --- |
| FPGA | field programmable gate array，現場可程式化閘陣列 |
| bitstream | 設定 FPGA 的位元檔（LUT 內容 + 開關設定） |
| NRE | nonrecurring engineering cost，一次性工程費（光罩） |
| per-unit cost | 每顆晶片的成本 |
| ASIC | application-specific integrated circuit |
| mask set | 光罩組，ASIC 製造的主要 NRE |
| LE (logic element) / CLB | 邏輯元件（Altera/Intel）／可設定邏輯區塊（Xilinx/AMD） |
| LUT (lookup table) | 查表，存真值表以實作任意小型組合函數 |
| IOE | input/output element，連接外界的可設定單元 |
| PLA | programmable logic array，FPGA 的前身，成本平方成長 |
| emulation | 把設計映射到 FPGA 上大量跑測試的驗證技術 |
| ILA | integrated logic analyzer，燒進 FPGA 的訊號記錄電路 |
| DSP slice | 硬式的乘加器單元 |
| block RAM | FPGA 內建的硬式記憶體區塊 |
| IP library | 廠商提供的現成模組（記憶體控制器、匯流排介面等） |
| constraint file | 指定腳位配置與目標時脈的檔案 |

## 所以呢

FPGA 的本質是「**用單價和速度換 NRE 和迭代時間**」。對 Wally 這種教學/研究專案，這個交換幾乎全是好處——不用付幾百萬做光罩，改設計幾分鐘就能重新燒錄，而且能接上真的 SD 卡和 DDR3 記憶體，做出一台真的能用的電腦。

下一節就是實作：一塊 $299 的 Arty A7 開發板，加上五個 AMD IP 模組（時脈產生、重設同步、AHB-to-AXI 橋接、跨時脈域、DDR3 控制器），把 Wally 變成一台跑 Linux 的電腦。
