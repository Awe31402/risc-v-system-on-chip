# 2.9 RISC-V Market

> 原書 p.80–85（Chapter 2: Introduction to RISC-V）

## 這節在講什麼

RISC-V 的商業現況：誰在做核心、做出什麼規格的核心。

主體是四張比較表（Table 2.10–2.13），把商用與開源的 RV64 / RV32 核心
**逐項規格並排**。這節的價值不在記住廠商名字（會過時），
而在**學會讀處理器規格表**——那些欄位就是本書後面每一章的主題。

而且這幾張表提供了**Wally 的座標**：跟業界核心並排，就知道 Wally 站在哪裡。

## 關鍵點

### 市場規模與成長

> "The RISC-V market has grown explosively since the architecture's inception at
>  Berkeley in 2010. As a clean and open architecture, RISC-V is addressing a huge
>  need in the semiconductor industry. By the end of 2021, more than 12 billion
>  RISC-V cores had shipped in commercial products [RV22]. In 2023, the SHD Group
>  forecasted that the RISC-V market would grow at a 40% compound annual growth rate
>  through 2030, with applications in hard drives, modems, televisions, artificial
>  intelligence, Internet of Things, gaming consoles, data centers, and smartphones."
> — p.80

中文解釋：**注意應用清單的組成**：硬碟、數據機、電視、AI、IoT、
遊戲主機、資料中心、智慧型手機。

**前面幾項（硬碟、數據機、電視）是「藏在裡面的控制器」**——
呼應 1.7 節說 RISC-V 的主戰場是取代各家的私有架構，
以及 1.6 節說「大多數 ARM 處理器嵌在使用者不知道有電腦的地方」。

**後面幾項（AI、資料中心、手機）才是正面戰場**，是未來式。

### 商業模式：IP 授權，和 Intel 的態度轉變

> "Most RISC-V cores are developed as intellectual property (IP) blocks in a hardware
>  description language and are licensed or available open source to SoC designers.
>  Intel became a premier member of RISC-V International in 2022 and established a
>  billion-dollar fund to support chip innovation, including fabrication of chips with
>  RISC-V processors."
> — p.80

中文解釋：**注意商業模式跟 ARM 是一樣的：賣 HDL 寫的 IP block。**
（呼應 1.2 節的 design reuse。）
差別在**底層的 ISA 不用付授權費**，而且**也可以直接拿開源的**。

**Intel 加入 RISC-V International 並設十億美元基金，是很強的訊號**——
1.6 節說 x86 是 Intel 的護城河，這裡它卻在支持競爭架構。
理由不難猜：Intel 現在也做代工（1.8 節），**客戶要什麼它就得做什麼**。

### 玩家名單

> "At the time of this writing, some of the commercial vendors with cores or SoCs for
>  sale or in development include Alibaba, Andes, Codasip, Esperanto, Microchip,
>  Rivos, Semidynamics, SiFive, Synopsys, Tenstorrent, and Ventana. Some of the most
>  widely known open-source cores include the Cadence VeeR (originally Western Digital
>  SweRV) family, Alibaba XuanTie family, and OpenHW Foundation CORE-V family."
> — p.80

中文解釋：**注意兩類玩家的分野**：
- **商用 IP 供應商**：SiFive（1.7 節提過，Krste Asanović 共同創辦）、Andes（台灣）、
  Synopsys、Ventana、Esperanto……
- **開源核心**：Cadence VeeR（原 Western Digital SweRV）、Alibaba XuanTie、
  **OpenHW CORE-V（Wally 屬於這家）**

有趣的是 **VeeR 原本是 Western Digital 的**——
一家硬碟公司做處理器、然後開源，正好對應前面的應用清單第一項。

### RV32 和 RV64 的分工

> "Whereas RV32 cores are often used as low-power embedded processors, RV64 cores are
>  often used as multicore application processors with memory-management units running
>  Linux or Android."
> — p.80

中文解釋：**這條分界線很清楚，記住它就能快速判斷一顆核心的定位：**

| | RV32 | RV64 |
| --- | --- | --- |
| 定位 | 低功耗嵌入式 | 多核應用處理器 |
| MMU | 通常沒有 | **有** |
| OS | 裸機或 RTOS | **Linux / Android** |

**分界的關鍵是 MMU 和虛擬記憶體**——要跑 Linux 就必須有（呼應 2.5 節的 S 擴充）。
所以 Wally 的 rv64gc 組態才能開 Linux，rv32imc 不行。

### 兩個極端的例子

> "Some RISC-V cores are targeting larger SoCs. For example, Esperanto's ET-SoC-1 is
>  a 7-nm chip with 1088 energy-efficient RV64 ET-Minion cores with vector units and
>  160-MiB of SRAM for machine learning. The Ventana Veyron V2 data center server SoC
>  contains up to 192 high-performance RV64GCV cores, tightly linked to domain-specific
>  accelerators."
> — p.80

中文解釋：**這兩個數字展示了 RISC-V 已經上桌的程度：**

| 晶片 | 規格 | 策略 |
| --- | --- | --- |
| **Esperanto ET-SoC-1** | 7nm、**1088 個**省電 RV64 核心 + 向量單元 + 160 MiB SRAM | **極多小核**，給機器學習 |
| **Ventana Veyron V2** | 最多 **192 個**高效能 RV64GCV 核心 + 領域專用加速器 | **較少大核** + 加速器 |

**1088 核**這個數字本身就說明了開源 ISA 的一個實際優勢：
**核心數乘上授權費會是天文數字**——免授權費在這種設計下差別巨大。

兩者都用了 **V（向量）擴充**——這正是 Wally 不支援的（2.8 節）。
也都搭配加速器，呼應 1.2 節的 SoC 設計哲學。

### 怎麼讀處理器規格表

中文解釋：Table 2.10–2.13（p.81–84）用同一組欄位比較各家核心。
**這組欄位就是「評估一顆處理器」的標準清單，值得記熟——
而且每一項都對應本書的某一章：**

| 欄位 | 意義 | 本書對應 |
| --- | --- | --- |
| **RV32/64 ISA** | 支援哪些擴充 / profile | 第 2.5 節 |
| **μArchitecture** | issue 寬度、in-order 或 out-of-order | 第 13、14 章 |
| **Pipeline stages** | 管線級數 | 第 7 章 |
| **L1 I$/D$、L2$、L3$** | 各級快取容量、line 大小、way 數 | 第 10 章 |
| **Branch predictor** | BHT / BTB / RAS 的大小 | 第 13 章 |
| **Multiplier / Divider latency** | 乘除法延遲 | 第 15 章 |
| **MMU** | Sv32/39/48、PMP、TLB 項數 | 第 11、16 章 |
| **Privilege levels** | M / MU / MSU / MSUH | 第 8 章 |
| **Bus** | AHB、AXI、TileLink、CHI… | 第 9 章 |
| **Frequency / Area** | 頻率與面積（含製程） | 第 6 章 |
| **CoreMark/MHz、SPECINT2006/GHz** | 效能分數 | 第 21 章 |

**四張表的重點觀察：**

**Table 2.10 商用 RV64 多核應用處理器（p.81）**——最高階的一群：
- SiFive P650/P550 是 **out-of-order、4 issue / 3 issue、13 級 pipeline**
- Ventana Veyron V2 **最多 15 issue、out-of-order、每叢集 3 核共 192 核、4nm、3.6 GHz**
- 對比 SiFive U54 是 **1 issue、pipelined、5 級**——**同樣是 RV64，跨度極大**
- 多數支援 **MSU 三種特權等級**，Ventana 和 P650 還有 **H**（hypervisor）
- 匯流排有 ACE/CHI/AXI、AHB/AXI、TileLink 等
- 國籍欄位值得注意（呼應 1.8 節）：多數 USA，Andes 是 Taiwan

**Table 2.11 商用 RV32 單核嵌入式處理器（p.82）**——對照組：
- pipeline 只有 **2 到 10 級**，多數 1 issue
- **面積小得多**：SiFive E20 只有 **0.046 mm²**（28hpc），E76 是 0.14 mm²
- 特權等級多為 **M** 或 **MU**（沒有 supervisor，跑不了 Linux）
- 很多**沒有 MMU、沒有分支預測器**（E20 三者皆無）
- 匯流排幾乎都是 **AHB/AXI**

**Table 2.12 開源 RV64 應用處理器（p.83）**——**Wally 在這張表的最後一欄**：

| | Berkeley BOOMv3 | T-Head C910 | **Wally (64gc)** |
| --- | --- | --- | --- |
| μArchitecture | 4 issue **Out-of-order** | 3 issue Out-of-order | **1 issue Pipelined** |
| Pipeline | ~14 級 | 12 級 | **5 級** |
| 分支預測 | TAGE | BHT/BTB/RAS | **Gshare** |
| CoreMark/MHz | 6.2 | 7.1 | **3.06** |
| 語言 | **Chisel3** | Verilog | **SystemVerilog** |
| 國籍 | USA | China | USA |

**Wally 的 CoreMark/MHz 大約是那些亂序核心的一半**——
這完全符合預期（單發射 vs 三四發射）。**Wally 不是要當最快，是要當最好懂。**

注意語言欄位的多樣性：**Chisel3（Berkeley BOOM）、BlueSpec（Madras Shakti C）、
SpinalHDL（VexRiscv）**——不是所有人都用 Verilog。
但 **Wally 選 SystemVerilog，因為它是業界主流**（第 2.10 節會明說）。

**Table 2.13 開源 RV32 嵌入式處理器（p.84）**——Wally (32imc) 也在最後一欄：
- **Wally (32imc)：5 級、1.9 GHz、0.043 mm²（28nm）、CoreMark/MHz 3.34**
- 對照 VeeR EH2：**9 級、superscalar dual-threaded、CoreMark/MHz 6.3**
  （呼應 2.8 節 benchmark 那段）
- 面積對比很有意思：VeeR EL2 是 **0.023 mm²（16nm）**，Wally 是 0.043 mm²（28nm）——
  **製程不同不能直接比**，這正是 2.8 節說要用 FO4 正規化的原因

書上最後很坦白（p.80）：
**"The RISC-V market is evolving rapidly, and it is too early to predict market
winners."** 以及 **"By the time you read this, there will undoubtedly be interesting
new cores."** ——**這節的具體資料會過期，方法（怎麼讀規格表）不會。**

## 名詞表

| 名詞 | 意思 |
| --- | --- |
| IP block | 以 HDL 描述、可授權或開源給 SoC 設計者的可重用模組 |
| Issue width | 發射寬度。一個週期能發射幾條指令（1 issue / 4 issue…） |
| In-order / Out-of-order | 循序 / 亂序執行 |
| BHT / BTB / RAS | Branch History Table / Branch Target Buffer / Return Address Stack |
| Sv32 / Sv39 / Sv48 | RISC-V 虛擬記憶體的三種分頁方案（數字為虛擬位址位元數） |
| PMP | Physical memory protection。實體記憶體保護 |
| MSU / MSUH | 支援的特權等級組合（Machine/Supervisor/User/Hypervisor） |
| AHB / AXI / TileLink / CHI | 常見的晶片內匯流排協定 |
| CoreMark/MHz、SPECINT2006/GHz | 正規化後的效能分數 |

## 所以呢

**這節真正的價值是那組規格欄位——它就是本書後面每一章的清單：
pipeline 級數（第 7 章）、特權等級（第 8 章）、匯流排（第 9 章）、
cache（第 10 章）、MMU（第 11、16 章）、分支預測（第 13 章）、乘除法（第 15 章）。**
而 Wally 的座標也很清楚：**單發射、5 級、CoreMark/MHz 約 3.0–3.4，
大約是亂序核心的一半效能**——它的目標是完整可讀，不是最快。
下一節（2.10）是本章總結與全書路線圖。
