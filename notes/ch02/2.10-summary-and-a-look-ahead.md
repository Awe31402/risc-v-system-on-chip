# 2.10 Summary and a Look Ahead

> 原書 p.85–88（Chapter 2: Introduction to RISC-V）

## 這節在講什麼

第 2 章總結 + **全書路線圖**。

前半把 RISC-V 架構濃縮成一頁（指令清單、暫存器慣例、特權架構、擴充與 profile）。
後半逐章說明每一章在做什麼——**這是全書最實用的一張地圖**，
以後想找某個主題在哪一章，回來查這節就對了。

## 關鍵點

### 這本書的教法：在真實實作的脈絡中教原理

> "This book is unusual in that it teaches you microprocessor and SoC design in the
>  context of a real processor implementation. Each principle covered in the book is
>  illustrated in the context of the Wally RISC-V processor. Logic verification is the
>  most difficult and time-consuming part of processor design, so each feature begins
>  with a test plan."
> — p.85

中文解釋：**兩個編排原則要記住，它們決定了每一章的長相：**
1. **每個原理都配一個 Wally 的真實實作**——不是抽象講解。
2. **每個功能都從 test plan（測試計畫）開始**，不是從實作開始。

第二點特別值得注意。**先寫測試計畫，再寫實作**——
理由在前面說過（1.2 節「驗證比設計貴」、2.8 節「沒測過的功能通常有 bug」）。
這在軟體界叫 test-driven，在硬體界是必須的，因為晶片流片後改不了。

### RISC-V 架構一頁摘要

> "As a fifth-generation RISC architecture, RISC-V defines the RV32I instruction set
>  with 40 simple instructions and a 32-entry register file of 32-bit registers.
>  Register x0 is tied to 0. The other register uses are flexible in principle, but
>  the RISC-V ABI convention consistently uses certain registers for certain purposes,
>  such as local variables (s0-s11), function arguments and return result (a0-a7),
>  function call return address (ra), the stack pointer (sp), and temporary results
>  (t0-t6)."
> — p.85

> "All instructions are encoded in a handful of 32-bit formats. The opcode and
>  source/destination registers are in the same location for every format,
>  facilitating a simple and fast decoder."
> — p.85

中文解釋：**第二段又強調了一次編碼格式的價值**（2.2 節詳述）——
這是全書第三次提到這件事，可見作者認為這是 RISC-V 最值得學的設計決定之一。

**完整指令清單**（p.85），這是比 2.1 節更好的速查版：

| 類別 | 指令 |
| --- | --- |
| R-type 算術/邏輯 | `add`, `sub`, `and`, `or`, `xor`, `sll`, `srl`, `sra`, `slt`, `sltu` |
| I-type 算術/邏輯 | `addi`, `andi`, `ori`, `xori`, `slli`, `srli`, `srai`, `slti`, `sltiu` |
| Loads / stores | `lw`, `lh`, `lhu`, `lb`, `lbu`, `sw`, `sh`, `sb` |
| Branches | `beq`, `bne`, `blt`, `bge`, `bltu`, `bgeu` |
| Jumps | `jr`, `jalr` |
| Upper immediates | `lui`, `auipc` |
| System | `ecall`, `ebreak`, `fence` |

**三句話講完整個 ISA 的行為**（p.85）：
- R-type 拿**兩個來源暫存器**運算，結果放目的暫存器
- I-type 一樣，但用**一個來源暫存器 + 12-bit 立即值**
- **RISC-V 是 load/store 架構**，所以搬資料只能用明確的 load 和 store
- 條件分支和無條件跳躍控制程式流

RV64I 的差異（p.85）：暫存器擴成 64-bit，加少量指令處理 double word 載入/儲存
以及只操作暫存器低 32 bit（W 後綴），**指令本身仍是 32 bit 長**。

最後一句是全章的價值宣言：
**"RISC-V avoids ideas that once seemed clever in other instruction sets but later
proved problematic for high-performance implementations."**（p.85）
——呼應 2.6 節那三個「過度聰明」的反面教材。

### 系統面摘要

> "RISC-V also defines a privileged architecture with three privilege levels, traps,
>  and CSRs. The memory map is system dependent, but a typical system has main memory
>  starting at address 0x80000000 and perhaps a boot memory at 0x1000, along with
>  various memory-mapped peripherals such as a timer, interrupt controller, and serial
>  port."
> — p.85–86

> "RISC-V has many standard extensions such as floating-point, which allows the
>  architecture to scale from a simple embedded microcontroller core to a full-featured
>  application processor. RISC-V profiles define a collection of extensions so that a
>  programmer has a standardized target for development."
> — p.86

中文解釋：三個系統層面的要點濃縮（分別對應 2.3、2.4、2.5 節）：
**三層特權 + trap + CSR**、**記憶體映射（0x80000000 主記憶體、0x1000 開機記憶體）**、
**擴充與 profile**。

注意 **"scale from...to..."** 這個字眼又出現了——**可擴縮性是 RISC-V 的核心賣點**，
整本書從 1.9 節到這裡講了三次。

### 全書路線圖（最實用的部分）

中文解釋：**這是本節最該留著查的內容。** 把第 3 到 23 章的分工整理成表：

**第一部分：工具與方法（第 3–6 章）**

| 章 | 內容 |
| --- | --- |
| **3** | RISC-V 編譯器與模擬器工具鏈安裝、Wally repo；組語與 C 的低階程式設計；**Spike、QEMU、Sail 模擬** |
| **4** | **HDL 實務**：SystemVerilog 教學、設計方法論與風格指南 |
| **5** | **邏輯驗證與除錯**（用 Wally 程式碼） |
| **6** | **邏輯合成**：把 Wally 各組態映射到 130、90、28 nm 製程，量化速度與大小 |

書上說明了為什麼選 SystemVerilog（p.86）：
**"Modern digital systems are specified and synthesized using hardware description
languages (HDLs), with SystemVerilog leading in industry."**

**第二部分：完整 pipeline 處理器（第 7–13 章）——全書最大的一部分**

> "The largest part of this book covers the design of full-featured pipelined
>  processors, including all the critical details usually glossed over in architecture
>  texts. Most chapters begin with principles applicable across computer architectures.
>  They then show how the principles are applied in practice in the RISC-V architecture.
>  They present a test plan showing how the features are verified and then illustrate a
>  real implementation with Wally."
> — p.86

**注意每章的固定四段結構：原理 → RISC-V 的做法 → 測試計畫 → Wally 實作。**
以及那句 **"all the critical details usually glossed over in architecture texts"**
（架構教科書通常一筆帶過的關鍵細節）——**這就是這本書的差異化定位。**

| 章 | 內容 |
| --- | --- |
| **7** | **完整 RV{32/64}I**：先單週期核心，再 5 級 pipeline（hazard、forwarding、stall、flush）。**假設理想的區域指令與資料記憶體** |
| **8** | **特權架構**：特權模式、trap、CSR |
| **9** | **匯流排介面**：從真實外部記憶體抓指令與資料 |

| **11** | **記憶體管理**：虛擬記憶體與記憶體保護 |
| **12, 13** | **LSU 與 IFU** 的整合：從 cache、內部記憶體或匯流排存取資料，同時支援虛擬記憶體與保護。**IFU 也含分支預測器** |

第 7 章先假設「理想的記憶體」，第 9–12 章才把記憶體系統做真實。
**這是典型的「先簡化再補齊」教學順序**，讀的時候要記得第 7 章的簡化在哪裡被解除。

## 所以呢

**這節是全書的索引，後面找不到某個主題時回來查這裡。**
最該記住的三條結構線：
1. **第 3–6 章是工具（工具鏈、HDL、驗證、合成）**，第 7–13 章是核心，
   第 14–19 章是擴充，第 20–23 章是系統整合。
2. **每一章的固定結構是：通用原理 → RISC-V 做法 → 測試計畫 → Wally 實作。**
3. **第 7 章假設理想記憶體，第 9–12 章才補上真實的記憶體系統**——讀時記得這個簡化。

下一章（第 3 章）開始動手：裝工具鏈、clone Wally、寫第一支程式。
