# 15.3 Test Plan

> 原書 p.606（Chapter 15: Extensions: M (Multiply and Divide)）

## 這節在講什麼

**兩句話 + 一張表。和第 14 章一樣，M 擴充由官方測試涵蓋。**

## 關鍵點

### 用既有的測試框架

> "**The M-extension instructions are tested with the riscv-arch-test suite. The configuration files to generate these
>  random tests are similar to the one described in Section 7.4. Table 15.4 lists the number of test cases for each
>  instruction.**"
> — p.606

中文解釋：**「組態檔和 7.4 節描述的那個類似」**——
呼應 7.4 節的 `riscv-ctg` 約束檔（所有暫存器、極值、walking ones/zeros、運算元對的關係）。

**M 擴充是非特權指令，所以官方測試涵蓋得好。**

### Table 15.4 的數字

中文解釋：**Table 15.4（p.606）：**

| Instruction | RV32M | RV64M |
| --- | --- | --- |
| `div` | 587 | 675 |
| **`divu`** | **722** | **821** |
| `divuw` | — | 820 |
| `divw` | — | 667 |
| `mul` | 583 | 680 |
| `mulh` | 583 | 673 |
| `mulhsu` | 645 | 740 |
| **`mulhu`** | **719** | **811** |
| `mulw` | — | 670 |
| `rem` | 582 | 662 |
| **`remu`** | **720** | **819** |
| `remuw` | — | 815 |
| `remw` | — | 672 |
| **Total** | **5,141** | **9,525** |

**三個觀察：**

**（1）無號版本的測試比有號版本多**
（`divu` 722 vs `div` 587；`mulhu` 719 vs `mulh` 583；`remu` 720 vs `rem` 582）。

**這有點反直覺**——直覺上有號要測的情況更多（正負組合）。
**可能的解釋：無號版本的極值範圍更大**
（0 到 2^32−1 vs −2^31 到 2^31−1），所以 corner case 的組合更多。

**（2）RV64 約是 RV32 的 1.85 倍**（9,525 / 5,141）——
比第 7 章和第 14 章的比例（約 1.7）稍高，因為 RV64M 多了五條 W 指令。

**（3）總數和其他章的對照：**

| 擴充 | RV32 | RV64 |
| --- | --- | --- |
| **I**（第 7 章） | 12,642 | 17,836 |
| **M**（本章） | **5,141** | **9,525** |
| **Zca**（第 14 章） | 4,632 | 7,829 |
| Zcb（第 14 章） | 957 | 1,496 |

**M 擴充只有 13 條指令卻有 5,141 個測試**——
平均每條約 400–800 個，和 I 擴充的 ALU 指令（約 580）相當。
**因為它們都是「兩個暫存器運算元」的指令。**

### 這節沒說但值得注意的

中文解釋：**Table 15.4 的測試涵蓋了 15.2.2 節的特殊情況嗎？**

**從 7.4 節的約束檔可以推測：**
- **「0」是標準的 corner case 之一** → **除以 0 應該有被測到**
- **「最負值」和「−1」也都在約束清單裡** → **溢位情況應該有被測到**

**但這節沒有明說**，而且也沒有提到 `Zmmul` 的測試
（因為 Zmmul 是 M 的子集，用 M 的測試扣掉除法即可）。

## 所以呢

**M 擴充由官方 riscv-arch-test 涵蓋，用和第 7 章相同的約束檔框架。**

**Table 15.4 的兩個觀察：**
1. **無號版本的測試比有號版本多**（可能因為無號的值域範圍更大）。
2. **13 條指令、5,141 個測試（RV32）**——
   平均每條 400–800 個，和 I 擴充的 ALU 指令相當
   （因為都是兩個暫存器運算元的指令）。

**15.2.2 節的特殊情況（除以 0、溢位）應該被 corner case 約束涵蓋，
但本節沒有明說。**
