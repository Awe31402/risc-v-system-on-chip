# 18.5 Summary

> 原書 p.765（Chapter 18: Extensions: Zb* & Zk* (Bit Manipulation and Cryptography)）

## 這節在講什麼

第 18 章的總結。把十幾個擴充名稱整理成一張清單，最後一段點出硬體成本的分布——這是全章最值得記住的結論。

## 關鍵點

### Zb* 四個擴充

> "In summary, the Zb* bit manipulation extensions are a family of four optional extensions that provide modest speedups for certain common code sequences: Zba: Shifts and adds to facilitate address generation. Zbb: Basic bit operations: min/max, rotate, zero/sign extension, count, combine, reverse. Zbc: Carry-less multiplication for cryptography and error checking codes. Zbs: Single-bit set/clear/invert/extract. B: Zba + Zbb + Zbs"
> — p.765

中文解釋：注意用詞「modest speedups」——書上很克制，沒有誇大。對照 18.1 開頭的數字：Embench 快 5%、密度好 4%、CoreMark 快 8%。

### Zk* 的完整清單

> "Zbkb: Bit manipulations generally useful for cryptographic algorithms. Zbkc: Subset of Zbc needed for cryptography. Zbkx: Permutations useful for implementing S-boxes in data-independent time. Zknd: Instructions for accelerating the decryption and key schedule functions of the AES block cipher. Zkne: Instructions for accelerating the encryption and key schedule functions of the AES block cipher. Zknh: Instructions for accelerating the σ and Σ functions for the SHA-2 family of hash functions. Zkn: NIST cryptography: Zbkb + Zbkc + Zbkx + Zkne + Zknd + Zknh. Zkt: Common data processing instructions must have data-independent latency. Zkr: Seed CSR to provide entropy for a random number generator. Zk: Zkn + Zkt + Zkr"
> — p.765

中文解釋：Zbkx 的描述特別把 **"in data-independent time"** 寫進去了，再次強調它存在的理由不只是加速，更是為了堵住 timing attack。

### 硬體成本的結論

> "Wally modifies the integer IEU to support the Zb* and Zkn extensions but lacks Zkr. The additional hardware is modest except that Zbc implies a large array of XLEN²/2 AND and XOR gates for the carry-less multiplier array, and RV64Zknd/Zkne implies sixteen 256 × 8-bit lookup tables for AES S-boxes."
> — p.765

中文解釋：這句話就是全章的成本總結。**「除了兩個例外，其餘都便宜」**：
- Zbc：XLEN²/2 個 AND 和 XOR 閘（RV64 就是 2,048 個）
- RV64 的 AES：16 張 256×8 查表

另外注意 Wally **沒有實作 Zkr**——熵源需要真正的隨機性來源（通常是類比雜訊電路），不是純數位邏輯能做的，超出這本書的範圍。

## 名詞表

| 名詞 | 意思 |
| --- | --- |
| modest speedups | 書上對 Zb* 效益的克制描述（5–8%） |
| XLEN²/2 | carry-less 乘法陣列的閘數量級 |
| Zkr | 熵源擴充，Wally 未實作 |

## 所以呢

第 18 章結束。第 19 章是一個「雜項」章節——把那些不夠大、不足以自成一章，但 RVA22S64 profile 又要求的擴充集中處理：快取管理（Zicbom/Zicboz/Zicbop）、非對齊存取（Zicclsm）、TLB 管理（Svinval）、pause hint（Zihintpause）、條件指令（Zicond），以及自訂擴充。
